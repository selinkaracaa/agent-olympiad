# 2009/puzzles/charity_work/PUZZLE

Charity Work Charity Work Introduction Hi there, space traveller! Thanks for helping out with our charity efforts here. We've got an important filing task ahead for you. Take the 32 Plutonians contained in this file. In order to properly identify what we can do to help them, we must categorize them and sort them accordingly. Filing Instructions 1. If the Plutonian has an odd number of eyes, enter C in the first box. Otherwise, enter B in the first box. 2. If the Plutonian has an odd number of ears, enter U in the second box. Otherwise, enter O in the second box. 3. If the Plutonian has an odd number of mouths, enter P in the third box. Otherwise, enter T in the third box. 4. If the Plutonian has an odd number of noses, enter A in the fourth box. Otherwise, enter E in the fourth box. 5. Sort by code, then Plutonian name, in alphabetical order. To verify your results, find the only cute Plutonian. Mark this Plutonian with a green paperclip. Starting with that Plutonian and going backwards through your list, read the last letter of each Plutonian's name until you have a six-letter word. Type in this word. Verification: Plutonians
