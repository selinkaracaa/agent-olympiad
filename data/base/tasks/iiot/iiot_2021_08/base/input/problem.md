Hash functions are meant to take as an input a large value, process it according to internal rules, and ﬁnally produce a smaller value. Since the number of possible diﬀerent output values is limited and smaller than the number of possible input values, by using a hash function one accepts the risk ofcollisions. A collision happens when two distinct input values, when hashed, give the same output value. Luca’s algorithm is rather simple, as the use case admits the possibil- ity of collisions, provided that they don’t grow too much. The input number is a sequence ofN decimal digits from1 to 9: d1, d2, . . . , dN. The hash is computed by multiplying each digit with the next one and reducing the result using the moduloM = 10 7 +19 = 10 000 019, until reaching the last digit.
