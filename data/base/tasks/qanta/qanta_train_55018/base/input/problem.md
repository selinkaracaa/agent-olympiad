# History

Mohawk Chief Hendrik and forty representatives of the Iroquois Confederation attended this event to negotiate peace following the Seven Years' War. Though it was originally rejected, it called for a Grand (*) Council where a number of representatives from each colony would be chosen based on the amount of taxes paid.
