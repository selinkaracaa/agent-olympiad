# Fine Arts

The violin solo, joined by solo oboe and horn passages, that closes this work's Andante Sostenuto second movement, marks the only time its composer ever set aside a solo specifically for the concertmaster. Meanwhile, following the dramatic Adagio introduction of the finale, an Allegro Non Troppo Ma Con Brio tempo brings in a switch into this work's parallel key of C major, features a horn solo that was modeled after the sound of an alpenhorn. Later followed by the composer's three other works of the same form in D Major, F Major, and E Minor, this piece contains a theme with an uncanny resemblance to the "Ode to Joy," one of many reasons critics nicknamed it "Beethoven's Tenth."
