[3 pts] Hasse Diagrams Suppose that a set S has a partial ordering ⪯. Then a Hasse diagram can be used to display the covering relation in a graphical way. The Hasse diagram is a graph whose vertices are the elements of S and where edges are drawn between two elements x and y if x≺y or y≺x and if there is no element z for which x≺z and z≺y or for which y≺z andz≺x. Also, y appears “above”x ifx≺y. Note that it is possible for more than one element to appear on the same level of a Hasse diagram. For example, the partially ordered set of divisors of 12, ordered by divisibility, is shown in Figure 1. In this diagram, the number 1 is said to be at Level 0 because it is the least divisor in the partial ordering shown. The numbers 2 and 3 are said to be on Level 1 because 2 ≻ 1 and 3≻ 1 and there is no number n such that 2≻n and n≻ 1 or 3≻n and n≻ 1. Other Levels are similarly deﬁned. [3 pts] Trinary Partitions A trinary partition of a positive integer n is an ordered n-tuple of non-increasing integers, each of which is either 0 or a power of 3, whose sum is n.
