33. [25] Given a function f, let π(f) = f ◦f ◦f ◦f ◦f. The attached sheet has the graphs of ten smooth
    functions from the interval (0, 1) to itself. The left-hand side consists of ﬁve functions:

      • F1(x) = 0.005 + 21 sin 2x + 41 sin 4x + 18 sin 8x + 161 sin 16x + 321 sin 32x;
      • F2(x) = F1(F1(x + 0.25));
      • F3(x) = F1((1 −x)F1((1 −x)2));
      • F4(x) = F1(x) + 0.05 sin(2πx);
      • F5(x) = F1(x + 1.45) + 0.65.

   The right-hand side consists of the ﬁve functions A, B, C, D, and E, which are π(F1), . . . , π(F5) in some
    order. Compute which of the functions {A, B, C, D, E} correspond to π(Fk) for k = 1, 2, 3, 4, 5.

   Your answer should be a ﬁve-character string containing A, B, C, D, E, or X for blank. For instance,
      if you think π(F1) = A and π(F5) = E, then you would answer AXXXE.  If you attempt to identify n
    functions and get them all correct, then you will receive n2 points. Otherwise, you will receive 0 points.
