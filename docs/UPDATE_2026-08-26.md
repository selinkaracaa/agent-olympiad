# Agent Olympiad — weekly update (2026-08-26)

**Project:** multi-agent teams on real olympiad contests under contest constraints  
**Matrix:** 4 model teams × 4 collaboration schemas = **16 runs per contest**  
**Results:** `results/phase_b/full_matrix/phase_b_matrix.json`

### How to read a cell

Each cell is **task · CS · IHS**

| Symbol | Meaning |
|---|---|
| **task** | Correctness vs gold (scale under each contest title) |
| **CS** | MultiAgentBench coordination (0–5): communication/planning *process* |
| **IHS** | Interaction helpfulness (0–5): whether chat/actions helped the *final answers* |

**CS ≠ IHS.** CS can be high while IHS is low if the team talked well but did not improve the answer sheet. IHS is the second collaboration metric . `—` = IHS still being scored post-hoc.

**Hetero × single_agent:** one Solo seat → GPT mini only; not a mixed team.

## Collaboration metrics

| Metric | Question it answers | Status |
|---|---|---|
| **CS** (MultiAgentBench) | Was communication/planning good as a *process*? | On all completed cells |
| **IHS** (interaction helpfulness) | Did interactions help the *final answers*? | Implemented; post-hoc rescoring in progress; also enabled for new live runs |

IHS labels each chat/action **helpful / neutral / hurt**, then returns 0–5 plus counts (`src/evaluation/collaboration_score.py`, `src/rescore_interaction_collab.py`).

### Instrumentation

New runs store **`tokens_by_turn`**: `[{turn, tokens, api_calls}, …]` beside the run total `tokens_used` (same estimated output tokens, `~chars/4`). Synthesis after the turn loop is attributed to the last turn. Existing matrix JSONs need a re-run to pick this up.
