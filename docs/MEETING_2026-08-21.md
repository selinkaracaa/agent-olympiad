## Framing (first impression)

This benchmark is **not** “can one unconstrained frontier model ace olympiad problems?”
Models already near-perfect IMO-style **problem-wise** evals.

We evaluate **collaboration under contest constraints**: limited turns / API / tools /
machines, real contest rules, many problems under one clock. A strong solo agent with
full resources can still fail when teammates have partial capabilities and must coordinate.

**Elevator line:** score **teams under contest rules**, not absolute unconstrained model skill.

---

## Feedback (3 + extras)

1. **Collaboration ≠ absolute ability** — always lead with constraints + teamwork.
2. **Prioritize competition-level evaluation** — full contest session (pressure, strategy,
   when to submit), not problem-by-problem homework. Paper story = competition-level.
3. **Weak-team vs strong-solo** — several weaker/open models collaborating should be
   compared to one strongest single agent with the **same total resource budget**.

Also: homogeneous + heterogeneous teams; ≥ ~5 baselines for reviewers; encode real
contest rules (e.g. ICPC wrong-submit penalty); prefer verifiable graders; anti-cheat
for answer lookup via search.
