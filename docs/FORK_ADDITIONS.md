# Additions on this branch (fork work)

This branch adds olympiad data **without modifying** the upstream core 12 tracks in `data/benchmarks/index.json`.

| File | Role |
|------|------|
| `data/benchmarks/index.json` | Upstream original 12 (immutable) |
| `data/benchmarks/index2.json` | Full primary session suite (34 tracks) |
| `data/benchmarks/index_aux.json` | Supplement corpora (6) |
| `data/raw/<new>/` | Pushable raw PDFs/JSON for new tracks |
| `from_zhongzheng/` | Domain catalog READMEs |
| `data/viz/` | Suite visualizations |

See also `.cursor/rules/upstream-benchmarks-immutable.mdc`.
