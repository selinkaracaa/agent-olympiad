# Work log — 2026-07-30 / 2026-07-31


## Meeting decisions implemented

1. **PDF input/output = text and/or page images** (no third special “PDF agent” path).
2. **Two modes:** question-level vs competition-level (packet scaffolding).
3. **Evaluators for all deliverable types:** gold *or* LLM-as-judge depending on type.
4. **Perplexity multi-image path** so we can smoke-test without OpenAI native PDF attach.
5. Connect last week’s **presentation evaluator** into the same unified system.


## Done

### Dual media (text + images)

- `src/artifacts/pdf_ingest.py` — extract text, rasterize pages (pymupdf), page slices, `max_pages` guard.
- Slide / document judges can attach **PDF** (OpenAI) or **page images** (Perplexity-friendly).

### Question vs competition packets

- `src/evaluation/modes.py` — `build_question_packet` / `build_competition_packet`.
- Full timed competition-level *agent runner* (ICPC-style strategy under the clock) is **not** built yet — only the packet/mode layer.

### Evaluators for all runnable types

- Enrichment script: `collectors/enrich_evaluation_metadata.py`  
  Writes `evaluation.evaluator_id` + `gold_label.parts` across every `data/benchmarks/*/benchmark.json`.
- **Gold:** `src/evaluation/gold.py` (multipart short answers when extractable).
- **Rubric LLM:** `src/evaluation/rubric_llm.py` for writing, proofs, memorials, worked packets, practical *reports*.
- **Slides:** existing `slide_deck_v1`, now shared via `src/evaluation/slides_pipeline.py`.
- Default rubrics under `data/rubrics/`.
- Registry updated: `data/evaluators/registry.json`.
- Unified CLI: `src/evaluate_submission.py`.

## How to try it

```bash
# Multimodal smoke (PDF pages → Perplexity)
export PERPLEXITY_API_KEY="pplx-..."
python3 src/smoke_multimodal.py data/raw/business_case/2024.pdf --pages 1-2

# Score a slide deck via shared slide_deck_v1 path
python3 src/evaluate_artifact.py results/demo_yusen/submission.pdf \
  --benchmark data/benchmarks/ieo_business_case/benchmark.json \
  --problem-id ieo_business_case_2024 \
  --provider perplexity --media images

# Refresh evaluation metadata on all benchmarks
python3 collectors/enrich_evaluation_metadata.py
```
